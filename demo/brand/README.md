# Institutional logo slot

Drop the official logo here and the console picks it up automatically on reload.

Accepted filenames (first match wins):

    unsw-logo.svg   unsw-logo.png   unsw-logo.jpg   unsw-logo.webp
    logo.svg        logo.png        logo.jpg        logo.webp

SVG is preferred — it stays sharp at the 30px masthead height.

No logo is bundled with this repo. The UNSW mark is a trademark and must come
from the university's own brand assets (UNSW Brand Hub / your faculty's
communications team). With no file present the masthead shows the type lockup
alone, which is the intended fallback rather than an imitation of the mark.
